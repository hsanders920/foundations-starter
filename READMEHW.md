HW- MadLibs
The game will involve the user playing madlibs for a short story the student has written.
At the beginning of the game, the user will be prompted to give x amount of adjectives, verbs, nouns, adverbs, based on the story the you have written.
Then, the story will be printed using the user's input.
The user will be prompted to play again.


You will be able to write code asking for a string to be inputted, and deal with many strings being utilized in a program. 
You will be able to write code using string formatting.
You will be able to trace how strings are stored in variables, lists and dictionaries and overwritten.

Task 1:
Prompt the user to input the words 
Specifically for the categories of adjectives, verbs, nouns, adverbs
Store the words and access them to insert the inputted values into the story (using a dictionary)

Task 2:
Write a story with proper formatting so that the users input goes in to the right section of text

Task 3:
Write code that prompts the user (y/n) on whether they would like to play again using an if statement  
If yes, will need to override stored data to play again
